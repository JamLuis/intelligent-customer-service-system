## 7. 流程图文字版

### 7.1 主流程

```text
客服坐席在 [智能问答工作台] 输入问题并提交
  -> 系统校验项目权限与文本合法性
  -> 创建 [问题会话 SupportSession]
  -> 若缺少关键上下文，则追问并等待补充
  -> 系统发起图谱检索和 MCP 实时查询
  -> 生成 [诊断案例 DiagnosticCase]
  -> 在 [诊断结果页] 展示根因、置信度、证据链、建议动作
  -> 用户可选择生成工单或审批单
  -> 审批通过后创建 [执行任务 ExecutionTask]
  -> 处理完成后沉淀到 [知识案例 KnowledgeCase]
```

### 7.2 异常流程

```text
若关键信息缺失
  -> 系统提示补充项目/设备/时间
  -> 保持会话在待补充上下文状态
若实时工具失败
  -> 系统展示静态知识结论并明确“实时证据缺失”
若审批未通过
  -> 系统终止执行，记录驳回意见，保留诊断案例
```
