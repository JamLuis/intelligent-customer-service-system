## 3. 二级功能拆解

### 3.1 [M1-F1] 会话建单与实体抽取

- **所属一级模块**：问题接入
- **优先级**：P0
- **业务目标**：把自然语言问题转换为结构化诊断入口。
- **触发场景**：用户提交“设备离线”“告警未触发”“数据异常”等问题。
- **涉及角色**：R-CS、R-OPS

| 步骤 | 用户动作 | 前置条件 | 操作位置（页面/入口） |
| --- | --- | --- | --- |

| 2 | 可选选择项目/设备 | 已知上下文 | 智能问答工作台 |
| 3 | 提交问题 | 基础字段已填写 | 智能问答工作台 |

#### 3.1.2 系统行为

| 步骤 | 系统动作 | 校验规则 | 输出/副作用 |
| --- | --- | --- | --- |

| 2 | 抽取项目、设备、时间、告警类型等实体 | 至少提取一个关键实体 | 生成结构化实体 |
| 3 | 创建问题会话 | 用户必须有项目权限 | 生成会话编号 |

### 3.7 [M6-F1] 系统执行日志

- **所属一级模块**：过程解释

- **触发场景**：每次发起诊断或重新诊断。
- **涉及角色**：R-CS、R-OPS、R-RD、R-ADMIN、R-AUDIT

| 维度 | 内容 |
| --- | --- |
| 用户操作 | 在问答页面点击“查看执行日志”，或在诊断结果页展开执行过程 |
| 系统行为 | 展示图谱命中、路径选择、MCP 调用、返回摘要、耗时、失败重试、降级原因和最终结论引用 |

| 权限控制 | 客服仅看摘要；运维可看详细证据；研发/管理员可看完整调用链；审计可导出只读日志 |

### 3.10 [M9-F1] MCP 能力管理

- **所属一级模块**：MCP 能力治理
- **优先级**：P0
- **业务目标**：展示系统内所有能力，明确能力边界，并支持启用或停用。
- **触发场景**：新增 MCP 工具、工具故障、风险等级变化、权限调整。
- **涉及角色**：R-ADMIN、R-AUDIT

| 维度 | 内容 |
| --- | --- |
| 用户操作 | 查看能力列表、能力简介、输入输出、风险等级、边界说明、调用记录；启用或停用能力 |
| 系统行为 | 保存能力状态，路径执行前校验能力是否启用；停用能力后自动触发路径重规划或降级 |
| 数据字段 | capabilityId、name、category、description、riskLevel、enabled、inputSchema、outputSchema、boundary、lastHealthStatus |
| 权限控制 | R-ADMIN 可启停和编辑边界；R-AUDIT 可查看调用审计；其他角色不允许修改 |

| 验收标准 | Given 管理员停用某 MCP 能力 When 相似诊断路径执行 Then 系统不得调用该能力并记录降级原因 |

### 3.11 [M10-F1] 诊断路径固化与重建

- **所属一级模块**：诊断路径治理
- **优先级**：P0
- **业务目标**：将成功链路沉淀为稳定路径，减少同类问题在不同时间的随机性。
- **触发场景**：一次诊断结果被用户确认有效，或用户反馈答案不符合现场。
- **涉及角色**：R-OPS、R-RD、R-ADMIN

| 维度 | 内容 |
| --- | --- |
| 用户操作 | 对答案标记有效/无效/部分有效，查看路径模板，提交重建，审核新路径版本 |
| 系统行为 | 命中相似问题时优先复用成功路径；失败反馈生成 RouteEvaluation；低成功率路径进入复核或停用 |
| 数据字段 | routeId、questionPattern、graphStrategy、mcpPlan、successRate、version、status、evaluationScore、failureReason |
| 权限控制 | R-OPS 可反馈和建议固化；R-RD 可审核关键路径；R-ADMIN 可启停、发布、回滚路径 |
| 异常状态 | 路径引用停用 MCP、图谱关系冲突、连续失败、用户反馈无效时必须重规划或转人工 |
| 验收标准 | Given 某类问题已有成功路径 When 用户再次提问相似问题 Then 系统优先复用路径并展示 routeId 和执行结果 |
