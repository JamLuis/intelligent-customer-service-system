## 3. 当前目标

- 当前阶段目标：完成需求固化、项目状态初始化、初始任务拆分与开发骨架创建。
- 本轮交付目标：明确 wnx-web + wnx-serve 场景下的智能客服系统初版边界，并提供可继续研发的工程目录。
- 当前不处理范围：真实生产鉴权接入、图数据库部署、向量索引方案、审批流引擎选型、数据库表结构与接口细节。

## 4. 关键规则

1. 未更新状态文档，不视为任务完成。
2. 未完成技术方案、数据库、API 文档，不允许进入核心集成开发。
3. 任何执行类工具必须遵守 L0-L5 分级与审批规则。
4. 所有结论必须带证据链，所有执行必须带审计链。
5. 新 Agent 接手前必须先读取恢复指南与主任务书，不得从零假设。
