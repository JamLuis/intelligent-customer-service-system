## 2. 已明确的信息

1. 项目目标不是通用 FAQ，而是面向设备监管、告警排障、配置诊断和运维协同的智能客服系统。
2. 核心形态为 Graph RAG + MCP 查询 + 诊断 Agent + 审批执行，且执行动作必须分级受控。
3. 主要覆盖问题类型包括使用问题、数据问题、设备问题、告警问题、配置问题、运维问题、对接问题。
4. 第一阶段只做问答与定位，第二阶段接入真实业务数据，第三阶段才进入半自动修复。
5. 主要目标系统是 wnx-web 与 wnx-serve，说明新系统需要围绕现有前端与后端做外挂式集成，而不是替代原系统。
6. 问答页面必须展示系统执行过程，包括图谱命中、MCP 调用、日志、推理路径和降级原因。
7. 系统需要图谱维护、知识源录入、MCP 能力管理、图谱-MCP 映射和诊断路径固化/重建能力。
8. 为降低同类问题的回答随机性，成功调用链需要固化，失败或不符合现场的答案需要触发路径重建。

## 3. 缺失的信息

| 编号 | 缺失项 | 为什么重要 | 不补齐的风险 | 建议补充方式 |
| --- | --- | --- | --- | --- |
| GAP-001 | wnx-web 可复用菜单、用户、权限体系 | 决定新系统是独立登录还是复用现有权限 | 重复建设账号体系，或导致跨系统鉴权失效 | 提供现有登录链路、token 模式、角色表说明 |
| GAP-002 | wnx-serve 可查询接口、日志、任务清单 | 决定 MCP 工具范围和第二阶段交付边界 | 诊断结论只能停留在静态知识，无法做实时核验 | 提供接口文档、日志检索入口、任务调度入口 |
| GAP-003 | 图谱初始数据来源优先级 | 决定知识图谱一期建模范围 | 图谱建设过大或缺失关键关系，导致检索质量差 | 明确代码扫描、数据库、协议文档、历史工单的优先级 |
| GAP-004 | 审批流责任角色与 SLA | 决定第三阶段执行闭环设计 | 执行动作无法落地或没有责任归属 | 明确审批人、抄送人、超时规则 |
| GAP-005 | 日志与监控平台现状 | 决定是否统一接 Loki / Elasticsearch / ClickHouse | 诊断证据链不完整，工具接口需要返工 | 明确当前日志平台、查询字段、保留周期 |
| GAP-006 | 安全与审计红线 | 决定哪些动作允许 L3，哪些必须 L4/L5 | 高风险动作可能被错误自动化 | 给出审计要求、合规要求和敏感操作名单 |
| GAP-007 | 目标性能指标 | 决定问答响应与批量诊断设计 | 架构阶段难以给出容量估算 | 明确并发量、峰值提问量、平均响应时间 |
| GAP-008 | 图谱人工编辑是否需要审核发布 | 决定图谱维护状态流和权限边界 | 错误关系可能直接进入生产诊断 | 明确管理员直接发布、双人审核或按风险分级审核 |
| GAP-009 | 知识源支持格式、OCR 质量和文件大小限制 | 决定知识录入验收标准 | 上传能力和解析质量不可控 | 明确 doc/excel/pdf/图片/文本的大小、页数、OCR 可接受准确率 |
| GAP-010 | 诊断路径固化粒度 | 决定路径模板是全局、项目级、问题类型级还是设备类型级 | 路径过粗会误用，路径过细会复用率低 | 由 PM、运维和研发共同确认粒度 |
| GAP-011 | 答案反馈维度和路径重建触发条件 | 决定何时重建、停用或复核路径 | 无效路径可能持续复用 | 明确有效/无效/部分有效、失败原因、人工复核规则 |
| GAP-012 | MCP 能力启停影响范围确认 | 决定停用能力后哪些路径受影响 | 固化路径可能调用已停用能力 | 增加影响路径清单和启停确认流程 |

## 5. 进入下一阶段判断

- 是否可进入需求固化：是
- 原因：产品目标、业务边界、阶段计划、关键角色与核心能力已经足够形成 PM 初版；缺失项主要影响架构、接口与集成细节，不阻塞需求固化。
- 下一阶段必须补齐项：接口清单、审批链路、鉴权方案、日志平台现状、图谱编辑审核规则、知识源录入约束、路径固化粒度、MCP 启停影响确认机制。

## 6. 需要向业务/研发追问的问题

1. wnx-web 现有用户、角色、项目权限是否要求复用到新系统？
2. wnx-serve 当前能稳定提供哪些查询接口、日志检索能力、任务状态能力？
3. 是否已有统一工单或审批系统，需要新系统直接接入，还是先自建审批单？
4. 一期是否需要覆盖除 wnx-web、wnx-serve 之外的其他设备平台？
5. 哪些动作明确被划为 L4/L5，不允许在一期试点环境下自动执行？
6. 图谱人工编辑是否需要审核发布？如果需要，审核人和 SLA 是什么？
7. 哪些角色可以启用或停用 MCP 能力，停用时是否必须确认受影响路径？
8. 调用链固化按项目、问题类型、设备类型还是全局生效？
9. 答案“不符合情况”的反馈入口、评价维度和必填原因是什么？
10. 知识库录入支持的文件大小、页数、OCR 质量要求和保留期限是什么？
