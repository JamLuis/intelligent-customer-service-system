# Intelligent Customer Service System 中断恢复指南

## 1. 当前项目状态摘要

- 当前阶段：项目初始化完成，产品经理阶段初版完成，待进入系统架构师阶段
- 最近完成任务：新项目目录初始化、PM 文档固化、monorepo 最小工程骨架创建
- 当前进行中任务：基础构建验证与后续架构阶段准备
- 当前阻塞：权限复用方案、实时接口清单、审批流归属未明确

## 2. 恢复顺序

新的 Agent 接手时，必须按以下顺序读取：

1. 00_输入与总控/02_项目总控说明.md
2. 00_输入与总控/03_项目状态总表.md
3. 00_输入与总控/04_决策记录.md
4. 00_输入与总控/05_变更记录.md
5. 00_输入与总控/06_风险与阻塞清单.md
6. 05_开发计划与Agent任务/10_Agent开发主任务书.md
7. 01_需求与业务分析 下的 04、04B、04C、04D、05 文档

## 3. 恢复检查项

| 检查项 | 是否完成 | 备注 |
| --- | --- | --- |
| 已确认当前阶段 | 是 | 当前应进入架构阶段而非重新做需求 |
| 已确认未完成任务 | 是 | 重点是架构、数据库、API、真实系统集成 |
| 已确认最新决策 | 是 | 已确认独立项目、三阶段落地、L0-L5 分级 |
| 已确认当前风险 | 是 | 接口、审批、权限是三大高风险点 |
| 已确认下一步动作 | 是 | 先做 07 系列文档，再做 08/09 文档 |

## 4. 继续执行前必须确认

1. 当前任务对应文档是否齐全。
2. 当前任务是否仍是最高优先级。
3. 是否有新的决策或变更影响当前任务。
4. 若要进入编码，是否已完成技术方案、数据库、API 设计。
