## 3. 当日重点关注

1. 架构文档已升级为 Unified Engineering Knowledge Graph，下一步优先补齐文档来源、脱敏范围、图谱复核规则和 PM-FB / BIZ-Q 量化项，不要直接跳数据库/API 设计。
2. 任何执行动作都必须先补齐审批与审计链路设计。
3. 图谱范围从“设备-协议-数据点-告警规则-页面/接口”升级为“代码 + 文档 + 协议 + 配置 + 数据库 + 工单 + 运维日志 + 接口 + 实时系统”全关联，但 Phase 1 仍按高频诊断链路收敛。
4. 问答页面必须作为“诊断工作台”设计，P0 需要执行日志、图谱路径、MCP 调用、路径反馈，不应只做普通聊天框。
