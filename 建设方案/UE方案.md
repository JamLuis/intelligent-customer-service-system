# 智能客服系统 AI业务场景驾驶舱设计规范

## 文档定位

### 建设目标  
本章节旨在为集团领导、甲方客户及监管单位提供一套完整的AI业务场景驾驶舱设计规范。通过明确用户画像、业务痛点及AI解决方案，展现AI能力如何有效支持业务决策与运营管理，最终实现提升效率、降低风险和创造商业价值的目标。

### 汇报对象  
- 集团高层管理者  
- 业务部门负责人  
- 甲方合作方  
- 监管机构及审计团队

### 设计原则  
本设计严格遵循“用户是谁→遇到什么问题→AI如何分析解决→最终结果→创造的价值”五步法，确保每个设计环节紧扣业务场景和用户需求，突出AI赋能和价值落地。  

1. **用户是谁**：明确使用者身份及其职责范围。  
2. **遇到什么问题**：详细描述业务痛点和决策难点。  
3. **AI如何解决**：说明AI技术和模型如何介入分析。  
4. **最终结果**：展示AI输出的可视化结果和洞察。  
5. **创造什么价值**：量化业务提升、风险降低及效率改善。

### 与技术架构章节的边界说明  
本章节聚焦于业务场景的用户体验设计和交互规范，不涉及底层技术架构、数据流和系统实现细节。技术架构相关内容由专门章节负责，确保设计与技术实现分层清晰，职责明确。

## 统一设计规范

### 页面尺寸与栅格系统  
- 标准设计分辨率为1920×1080像素。  
- 采用24列等宽栅格系统，方便响应式布局与组件对齐。  
- 水平边距设置为24px，列间距为16px，保证内容层次清晰且视觉舒适。

### 主题风格规范  
- 整体采用深色科技风，基调为黑灰渐变背景，突出数据和图表。  
- 参考Apple Vision Pro、Palantir Gotham及Tesla FSD风格，强调现代感与专业感。  
- 玻璃拟态（Glassmorphism）卡片设计，带有半透明背景和柔和阴影，提升层次感。

### 字体规范  
- 标题字号：32px，字重700，颜色#FFFFFF。  
- 副标题字号：20px，字重600，颜色#CCCCCC。  
- 正文字号：14px，字重400，颜色#AAAAAA。  
- 指标数字字号范围48~72px，字重700，颜色根据指标状态动态调整。

### 色彩规范  
- 背景色：#121212（深灰黑）  
- 成功色：#4CAF50（绿色）  
- 警告色：#FF9800（橙色）  
- 危险色：#F44336（红色）  
- 信息色：#2196F3（蓝色）  
- 文字主色：#FFFFFF  
- 文字次色：#CCCCCC

### Glassmorphism卡片规范  
- 圆角：12px  
- 背景透明度：40%（rgba白色或黑色混合）  
- 阴影：0 8px 32px rgba(0, 0, 0, 0.37)  
- 边框：1px rgba(255, 255, 255, 0.1)半透明线条

### 图表规范  
- 采用简洁现代的柱状图、折线图、饼图，颜色与整体色彩体系一致。  
- 重点数据采用渐变色突出，辅助数据用浅色调。  
- 图表交互支持悬浮提示、筛选和动态更新。

### GIS地图规范  
- 地图底色采用暗色系，突出风险热力区域。  
- 支持多层叠加，包括热力图、标记点、轨迹线。  
- 地图交互支持缩放、平移及点击弹窗展示详细信息。

### AI分析卡片规范  
- 卡片包含标题、关键指标、趋势图及简要分析文本。  
- 采用Glassmorphism风格，突出层次感。  
- 关键指标颜色根据状态动态调整（成功、警告、危险）。

### MCP动作按钮规范  
- 主要按钮尺寸48×48px，圆角8px。  
- 颜色区分操作类型：主操作蓝色(#2196F3)、警告橙色(#FF9800)、危险红色(#F44336)。  
- 支持点击反馈动效及禁用状态。

### 动效规范  
- 数字滚动动画平滑，时长0.5秒。  
- 地图热力区域呼吸光效，周期3秒。  
- AI输出采用打字机效果，模拟实时生成感。  
- 按钮点击及页面切换均采用渐隐渐现动画，增强用户体验。

# 16.1 集团安全运营驾驶舱

### 页面定位  
集团安全运营驾驶舱为集团安全管理层提供实时风险监控与分析支持，集成多维度风险数据与AI洞察，实现风险预警、原因分析及决策辅助，保障集团安全运营稳定。

### 使用角色  
- 集团安全总监  
- 风险管理部门负责人  
- 运营调度主管  
- AI分析师

### 用户核心问题  
- 今日整体安全告警情况如何？  
- 哪些线路和车辆风险最高？  
- 风险趋势变化及区域分布如何？  
- AI如何辅助发现潜在风险及预测未来风险？  
- 应采取哪些专项检查和维修建议？

### 页面目标  
- 实时展示关键安全指标与风险态势。  
- 通过地图和排行分析定位风险热点。  
- 利用AI洞察揭示风险成因和未来趋势。  
- 支持快速生成专项检查工单，优化排班和维修计划。

### 页面布局  
- 顶部导航区，高度80px，包含系统名称、用户信息和全局搜索。  
- KPI指标区，高度160px，横向排列四个核心指标。  
- 主体内容区分为左中右三栏：  
  - 左侧风险热力地图区（宽度40%）  
  - 中央风险分析区（宽度35%）  
  - 右侧AI洞察区（宽度25%）  
- 底部AI决策区，高度140px，横向排列专项检查、排班优化、维修建议三个操作按钮。

### 顶部导航区  
- 字段：系统Logo、当前日期时间、用户头像及名称、全局搜索框。  
- 位置：左侧Logo及名称，右侧用户信息和搜索。  
- 组件：文本、图标按钮、输入框。

### KPI指标区  
- 今日告警：数字示例120，颜色#F44336，图标为警告符号。  
- 高风险线路：示例5条，颜色#FF9800，线路图标。  
- 高风险车辆：示例12辆，颜色#FF9800，车辆图标。  
- 事故风险指数：数值0.78（0~1），颜色#4CAF50，趋势向下箭头。  
- 布局：四个指标横向均分，支持点击跳转详细分析。

### 左侧风险热力地图区  
- 地图显示集团所有运营线路及车辆分布。  
- 热力区域用红橙黄渐变表示风险等级。  
- 支持点击热区弹出详细风险信息窗口（包含线路名、告警数、风险评分）。  
- 地图支持缩放、平移及GIS联动。

### 中央风险分析区  
- 线路排行：按风险指数排序，显示前10条线路，含风险等级图标。  
- 分公司排行：展示各分公司风险总分及同比变化。  
- 趋势分析：折线图展示过去30天风险指数变化趋势。  
- 交互支持筛选时间范围和风险等级。

### 右侧AI洞察区  
- 风险发现：AI自动识别的潜在风险点列表。  
- 原因分析：基于AI模型的风险成因文本及关键词高亮。  
- 72小时风险预测：风险指数预测曲线及预警等级。  
- 卡片设计采用Glassmorphism，配有图标和动态数据。

### 底部AI决策区  
- 专项检查按钮：蓝色，名称“创建专项检查工单”，调用接口/workorder/create。  
- 排班优化按钮：橙色，名称“调整排班计划”，弹出排班调整面板。  
- 维修建议按钮：绿色，名称“生成维修建议”，展示维修方案列表。  
- 三个按钮均支持快捷操作和状态反馈。

### MCP调用说明  
- 创建专项检查工单接口：POST /workorder/create  
- 参数包含风险点ID、检查内容、优先级、负责人。

### 用户操作流程  
1. 用户登录驾驶舱，查看今日告警及风险指标。  
2. 通过热力地图定位高风险区域，点击查看详情。  
3. 在风险分析区筛选重点线路和分公司。  
4. 参考AI洞察区提供的风险原因及预测。  
5. 通过底部决策区创建专项检查工单或调整排班。  
6. 监控工单执行状态，持续跟踪风险变化。

### 页面汇报价值  
- 实时掌握集团安全风险全貌，提升预警响应速度。  
- 通过AI辅助分析，精准定位风险成因，减少误判。  
- 支持快速决策与执行，降低事故发生概率。  
- 提升安全管理效率，保障集团运营稳定。


### 数字孪生可视化设计

#### 设计理念
本页面从传统的图表数据展示升级为基于真实世界模型的数字孪生驾驶舱。通过 GraphRAG 构建业务知识图谱，结合地图仿真、热力叠加、车辆状态可视化与 AI 语音交互，实现风险监控从抽象数据到具象场景的转变。

#### 核心实体与关系
页面呈现以下核心实体及其关系：
- **片区**：京口区、润州区等运营区域
- **线路**：K12 快速公交、K18 城市支线、B2 夜班线路
- **场站**：公交一场、公交二场、公交三场、南徐场站
- **车辆**：1,247 辆在运公交，实时显示位置与状态
- **司机**：与车辆绑定，支持快速定位

支撑实体：
- **设备**：CAN-9907、摄像头等车载设备
- **协议**：JT/T 808、JT/T 1078 等通信协议
- **告警规则**：紧急制动、疲劳驾驶、超速、设备离线等

#### 地图主视图区
采用深色科技风地图底图，支持以下图层叠加：

**1. 热力图层（来自高德）**
- 数据源：高德地图实时路况 API
- 颜色编码：
  - 绿色：低繁忙度（畅通）
  - 橙色：中繁忙度（缓行）
  - 红色：高繁忙度（拥堵）
- 动画效果：热力区域呼吸脉动，周期 4-6 秒

**2. 线路图层**
- 颜色编码表示线路健康状态：
  - 绿色（#4CAF50）：安全线路，无告警或低风险
  - 橙色（#FF9800）：可能有问题，存在预警
  - 红色（#F44336）：风险路线，告警频发
- 线路以虚线动画形式呈现，支持点击查看详情

**3. 车辆标记层**
- 车辆以圆点标记，颜色表示状态：
  - 绿色：正常运行
  - 橙色：预警状态（疲劳驾驶、超速等）
  - 红色：告警状态（紧急制动、设备离线等）
- 告警车辆显示脉冲动画，吸引注意力
- 点击车辆显示详细信息卡片：
  - 车牌号
  - 所属线路
  - 当前司机
  - 告警类型（如有）

**4. 场站标记层**
- 场站以方形标记，蓝紫渐变色
- 显示场站名称标签

**5. 区域标注层**
- 片区名称：京口区、润州区
- POI 标注：镇江南站、大市口、丁卯桥

#### 右侧浮动面板

**1. 持续告警车辆列表**
- 位置：地图右侧，垂直排列
- 功能：
  - 实时显示所有正在告警的车辆
  - 按告警等级排序（P1 优先）
  - 显示车牌、线路、告警类型、持续时间
- 视觉设计：
  - P1 告警（高危）：左侧红色边框 + 右侧红色脉动条
  - P2 告警（中危）：左侧橙色边框
  - 点击可定位到地图上的车辆

**2. AI 语音助手面板**
- 位置：告警列表下方
- 功能：
  - 支持语音或文字提问
  - 基于 GraphRAG 知识图谱进行关系推理
  - 调用 MCP 获取实时数据（高德路况、交管局信息）
  - 提供智能分析与建议
- 交互示例：
  - 用户："K12 线路今天为什么这么多告警？"
  - AI 回答：结合知识图谱推理 + 高德路况数据 + MCP 实时接口，给出多维度分析
- 数据来源标签：GraphRAG、高德路况、MCP

**3. 图例面板**
- 位置：右侧面板底部
- 内容：
  - 线路状态图例（绿/橙/红）
  - 车辆状态图例（绿/橙/红）
  - 热力图图例（渐变色条）

#### 动效规范
- **热力脉动**：4-6 秒周期，scale 1.0 → 1.15，opacity 0.4 → 0.6
- **车辆告警脉冲**：1.5-2 秒周期，圆环扩散动画
- **高危告警条**：2 秒周期，opacity 0.3 → 1.0
- **地图网格**：静态，提供空间参考

#### 技术实现要点
- 地图底图：CSS Grid + 渐变背景模拟
- 热力图：CSS radial-gradient + filter: blur
- 线路：SVG path 动画
- 车辆标记：绝对定位 + 脉冲动画
- 告警列表：Flexbox + 滚动容器
- AI 对话：气泡式布局，支持 Markdown 渲染

#### 数据流说明
```
用户提问 → AI 语音助手
  ↓
GraphRAG 知识图谱查询
  ↓
关系推理（车辆-线路-告警-设备）
  ↓
MCP 调用实时接口（高德路况、交管局）
  ↓
综合分析与建议生成
  ↓
用户确认 → 执行动作（创建工单、调整排班）
```


# 16.2 智能调度中心

### 页面定位  
智能调度中心为调度管理人员提供实时车辆状态与位置监控，融合AI分析与视频联动，优化调度决策，实现高效运营和安全保障。

### 使用角色  
- 调度主管  
- 车辆管理人员  
- AI运维分析师

### 用户问题示例  
- “苏L03215现在具体位置在哪？”  
- “当前车辆速度和方向是否正常？”  
- “急刹次数是否异常？”  
- “ECU、ABS、CAN状态是否正常？”  
- “调度建议有哪些？”

### 页面布局  
- 顶部导航栏，包含系统名称、用户信息。  
- 左侧GIS实时车辆地图（占比60%宽度）。  
- 右侧垂直排列三大面板：实时状态卡片、AI分析面板、视频联动面板。  
- 底部调度建议面板，横向展开。

### GIS实时车辆地图  
- 实时显示所有车辆位置，支持车牌搜索及定位。  
- 车辆图标根据状态（正常、异常）变色。  
- 地图支持缩放、平移、轨迹回放功能。

### 实时状态卡片  
- 显示选中车辆信息：车牌（如苏L03215）、速度（km/h）、方向（度）、驾驶员姓名、所属线路。  
- 颜色状态指示正常（绿色）、警告（橙色）、异常（红色）。  
- 支持一键刷新和历史状态查看。

### AI分析面板  
- 急刹统计：近24小时急刹次数，阈值红色预警。  
- ECU状态：在线/离线，异常高亮。  
- ABS状态：正常/故障状态指示。  
- CAN状态：通信状态监控。  
- 采用图表和状态灯结合展示。

### 视频联动面板  
- 支持调取车辆摄像头实时视频及历史回放。  
- 视频播放控制（暂停、快进、慢放）。  
- 视频与车辆状态联动，异常自动弹出。

### 调度建议面板  
- 基于AI分析结果，提供调度优化建议。  
- 包含车辆调度调整、路线优化、司机提醒等。  
- 支持一键执行调度指令。

### MCP接口  
- /vehicle/realtime/location：实时车辆位置数据接口。  
- /video/playback/query：视频回放查询接口。  
- /can/latest/data：CAN总线最新状态数据接口。

### 用户操作流程  
1. 调度员登录系统，查看GIS实时车辆分布。  
2. 选中车辆查看实时状态卡片及AI分析结果。  
3. 调用视频联动面板查看异常车辆视频。  
4. 参考调度建议面板调整车辆调度。  
5. 监控调度执行效果，持续优化。

### 页面汇报价值  
- 实时掌握车辆动态，保障运输安全。  
- AI辅助异常检测，提升调度响应速度。  
- 视频联动提升事故分析能力。  
- 优化调度方案，提升运营效率。

# 16.3 安全监管中心

### GIS风险分析大屏  
- 大屏展示集团全网风险分布，采用深色地图背景。  
- 支持多层次风险叠加展示，包括偏航热力图、告警点。  
- 地图交互支持区域缩放、点击查看详细风险数据。

### 偏航热力图  
- 以红黄渐变颜色显示偏航次数密集区域。  
- 热区点击弹出区域偏航详情，包括次数、时间分布。  
- 支持按时间段筛选（如近7天、30天）。

### 风险区域排行  
- 展示水域、航线、船舶风险评分排名。  
- 每项包含偏航次数、告警等级、风险评分（0~100）。  
- 支持导出及筛选功能。

### AI监管洞察
