## 4. 禁止拆分错误

1. 不要把“实现知识图谱”作为单任务。
2. 不要让前端 Agent 自己定义实体/关系类型。
3. 不要让 Python Agent 直接写 Neo4j。
4. 不要让 Java Agent 跳过 review task 直接发布 LLM 关系。
5. 不要让测试 Agent 只测页面，不测 Neo4j/PG 真实数据。
6. **不要在 Neo4j 中动态拼 Label / 动态拼关系类型名（仅允许 `:KnowledgeEntity` + `:RELATION` + `:SourceBlock/:Document/:Section`，业务类型一律走属性）。**
7. **不要在归一/合并中仅靠 embedding 高似就 auto-merge，必须走 Canonical Resolver 加权评分。**
8. **不要在诊断检索/邻居/路径查询中走未携 Traversal Budget 的 Cypher。**
9. **不要让纯向量召回直接返回诊断结论，必须走 Hybrid Retrieval。**
