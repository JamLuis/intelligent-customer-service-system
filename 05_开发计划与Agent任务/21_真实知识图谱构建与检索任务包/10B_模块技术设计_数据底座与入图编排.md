# 模块技术设计：数据底座与入图编排

## 1. 文档信息

- 对应模块：真实 KG 数据底座与 Java 入图编排
- 关联架构章节：`07F` §8、§9、§12、§15
- 关联任务：KG-DB-001~003、KG-BE-001~008
- 编写人：Copilot 技术负责人
- 版本：V0.1

## 2. 模块概述

- 业务目标：把知识源、解析块、候选实体/关系、复核任务、图谱版本和 Neo4j 节点关系形成真实可追溯数据链路。
- 服务对象：后台管理员、运维工程师、诊断检索服务、前端图谱维护页。
- 核心场景：创建知识源、触发解析/抽取/构建、保存候选、生成复核、写 draft 图谱、发布/回滚。
- 上游依赖：07F、API 契约、Python parse/extract 返回。
- 下游被依赖：前端录入页、历史维护页、诊断检索、测试链路。
- 数据所有权：PostgreSQL 元数据由 Java 后端持有；Neo4j 图谱写入由 Java 后端统一控制。

## 6. 关键类设计

### 6.1 `KnowledgeApplicationService`

- 职责：source 创建与 action 总入口。
- 输入：source create request、source action request。
- 输出：source detail、task status。
- 异常：sourceType 不支持、graphCategory 不存在、状态非法、AI service 失败。
- 依赖：KnowledgeSourceService、IngestionTaskService、AiGraphClient。

### 6.2 `GraphAssetService`

- 职责：图谱资产、草稿、发布、回滚。
- 输入：graphId、revisionId、draft changes、version action。
- 输出：graph detail、active revision、操作结果。
- 异常：未处理冲突、并发版本冲突、无发布权限。
- 依赖：PgGraphMetadataRepository、Neo4jGraphRepository、AuditService。

### 6.3 `Neo4jGraphRepository`

- 职责：参数化 Cypher 写入和查询。
- 输入：GraphDraftPlan、GraphQueryRequest。
- 输出：nodes、edges、paths。
- 异常：连接失败、约束冲突、查询超时。
- 依赖：Neo4j Driver。
