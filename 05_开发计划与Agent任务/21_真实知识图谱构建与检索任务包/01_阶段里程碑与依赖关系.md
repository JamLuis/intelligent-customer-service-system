# 阶段里程碑与依赖关系

## 1. 里程碑总览

| 里程碑 | 名称 | 目标 | 退出标准 | 可并行任务 |
| --- | --- | --- | --- | --- |
| KG-M0 | 契约冻结 | 数据库增量、API 增量、taxonomy seed 明确 | migration/API 文档/错误码/Mock 场景完成 | DB、接口可并行，但接口不得先于字段冻结合并 |
| KG-M1 | 真实数据底座 | PostgreSQL + pgvector 表、索引、seed 可用 | `verify-infra` 后表存在、seed 可查、vector index 可用 | DB 与 Java Repository 骨架 |
| KG-M2 | 解析与候选抽取 | Python 能把样例文件解析为 blocks/candidates | text/json/csv/docx/xlsx/pdf 基础样例通过 | Python parser、rule extractor、LLM adapter mock |
| KG-M3 | Java 入图编排 | Java 能创建 source、保存 block/candidate、构建 graph batch | source -> block -> candidate -> graph_build_batch 记录可查 | Java API、Python 集成 |
| KG-M4 | Neo4j 草稿与发布 | draft revision 写 Neo4j，发布后 active revision 可检索 | Neo4j 有节点/关系，published 查询只命中 active revision | Java Neo4j、前端预览 |
| KG-M5 | 管理端可用 | 前端录入、候选预览、历史维护、证据抽屉可用 | 页面使用真实 API，不再依赖 MockSupportService 图谱资产 | 前端与后端联调 |
| KG-M6 | 诊断检索闭环 | 诊断可用图谱路径 + pgvector evidence + MCP 建议能力 | `/graphs/search/diagnosis` 返回路径、证据和建议 MCP | Java search、Python retrieval plan |
| KG-M7 | 测试与交付 | 全链路、权限、版本、回滚、性能 smoke 完成 | 测试报告、阻塞清单、交接单完成 | 测试、主控收尾 |

## 2. 合并顺序

```text
KG-M0 契约冻结
  -> KG-M1 数据底座
  -> KG-M2 解析抽取
  -> KG-M3 Java 入图编排
  -> KG-M4 Neo4j 草稿/发布
  -> KG-M5 前端管理端
  -> KG-M6 诊断检索
  -> KG-M7 测试交付
```

## 4. 关键阻塞规则

1. DB migration 未完成前，后端 Agent 只能写 DTO 和接口占位，不得写真实 Repository 逻辑。
2. API 文档未补齐前，前端 Agent 只能实现组件骨架，不得自造字段。
3. Python Parser 未完成基础 block schema 前，Java 不得假设 block 字段。
4. Neo4j draft/publish 未完成前，诊断检索只能返回降级提示，不得使用 draft 图谱。
5. 回滚链路未完成前，前端不得提供“发布到正式图谱”的显式入口，只能保存草稿。

## 5. Agent 并行策略

| 并行组 | 可并行任务 | 不可同时改动 |
| --- | --- | --- |
| P1 | DB migration、接口文档初稿、Python parser skeleton | `04_数据库与API/09_API文档.md` 由接口 Agent 主改 |
| P2 | Java DTO/Controller skeleton、Python parser/extractor、前端组件 skeleton | OpenAPI/DTO 字段未冻结前不得硬编码最终字段 |
| P3 | Java Repository/Service、前端接真实 API、测试样例 | `frontend/src/api.ts` 需由前端 Agent 统一维护 |
| P4 | 诊断检索、MCP Planner、E2E 测试 | 诊断响应契约变更必须先回写 API 文档 |

## 6. 每阶段必交物

| KG-M0 | migration 草案、API 增量文档、错误码、taxonomy seed 清单 |

| KG-M3 | Java Controller/Service/Repository、任务状态转换测试、AI client 调用测试 |
| KG-M4 | Neo4j constraints/index、draft/publish/rollback smoke、Cypher 查询样例 |

| KG-M6 | diagnosis search API、query log、证据合并、MCP 建议能力输出 |
| KG-M7 | 测试报告、遗留风险、交接单、状态/变更记录更新 |
