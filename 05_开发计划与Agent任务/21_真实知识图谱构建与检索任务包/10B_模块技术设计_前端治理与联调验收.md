## 1. 文档信息

- 对应模块：前端图谱治理页面与测试联调
- 关联架构章节：`07F` §17、§18、§22

- 编写人：Copilot 技术负责人
- 版本：V0.1

## 2. 模块概述

- 业务目标：让用户能看到真实入图过程、候选实体关系、图谱版本、证据溯源和诊断图谱路径。
- 服务对象：运维工程师、管理员、审计人员、测试 Agent。
- 核心场景：录入知识源、查看任务、候选复核、维护历史图谱、查看证据、诊断检索展示。
- 上游依赖：KG API、Java 后端真实数据、Python 解析抽取。
- 下游被依赖：测试验收、用户操作培训。
- 数据所有权：前端不持久化权威数据，只展示和提交操作请求。

## 3. 后端实现拆分

前端依赖以下后端能力：taxonomy、source、blocks、candidates、review tasks、graph assets、graph detail、draft save、publish/rollback、diagnosis search。

## 6. 关键组件设计

### 6.1 `GraphCategorySelector`

- 职责：从 taxonomy API 展示分类、实体类型、关系类型。
- 输入：categories、entityTypes、relationTypes、modelValue。
- 输出：selected graphCategoryId、entityType、relationType。
- 异常：taxonomy 加载失败。
- 依赖：api.getGraphTaxonomy。

### 6.2 `CandidateReviewTable`

- 职责：展示 candidate entity/relation。
- 输入：entities、relations。
- 输出：review action、select evidence。
- 异常：空候选、冲突候选。
- 依赖：KG-004、KG-014、KG-015。

### 6.3 `EvidenceDrawer`

- 职责：展示 source/block/page/section/rawText 摘要。
- 输入：entityId/relationId/evidenceRefs。
- 输出：无。
- 异常：无权限查看原文时显示脱敏提示。
- 依赖：KG-013。

### 6.4 `GraphEditor`

- 职责：关系图展示、草稿编辑。
- 输入：nodes、edges、entityTypes、relationTypes、revision。
- 输出：draft changes。
- 异常：版本冲突、保存失败。
- 依赖：Vue Flow、KG-008。
