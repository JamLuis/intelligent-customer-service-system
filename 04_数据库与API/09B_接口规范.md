# Intelligent Customer Service System 接口规范

## 1. 适用范围

- 适用版本：V0.1 P0
- 适用接口：问答会话、执行日志、知识录入、图谱查询、MCP 能力、路径反馈、审计查询
- 接入方式：前端统一访问 Java Backend；Java Backend 通过 Adapter / MCP Server / AI Service 访问下游能力
- V0.1 约束：真实 wnx 接口未齐时使用 Mock + Adapter，前端不得直接依赖 wnx 原始字段

## 2. 基础约定

| 项 | 规范 |
| --- | --- |
| Base Path | `/api/v1` |
| Content-Type | `application/json; charset=utf-8`，文件上传使用 `multipart/form-data` |
| 字符集 | UTF-8 |
| 时间格式 | ISO-8601，例：`2026-05-23T10:30:00+08:00` |
| ID 类型 | UUID 字符串 |
| 金额/比例 | 本系统 V0.1 无金额；置信度、进度使用 0-100 数值 |
| 布尔字段 | `true` / `false` |
| 空数组 | 返回 `[]`，不返回 `null` |
| 空对象 | 返回 `{}`，不返回 `null` |

## 3. 鉴权与请求头

| Header | 必填 | 说明 |
| --- | --- | --- |
| Authorization | 是 | `Bearer <accessToken>` |
| X-Project-Id | 条件必填 | 当前项目上下文；涉及项目数据的接口必填 |
| X-Request-Id | 是 | 前端生成或网关生成，用于链路追踪 |
| X-Idempotency-Key | 写接口必填 | 创建/提交/启停/反馈等写接口必填，建议 UUID |
| X-Client-Timezone | 否 | 客户端时区，默认 Asia/Shanghai |

## 4. 统一响应结构

### 4.1 成功响应

```json
{
  "code": "0",
  "message": "success",
  "requestId": "7e1b7b2f-98bd-4f7f-8f35-c2d6e71f7f31",
  "data": {}
}
```

### 4.2 失败响应

```json
{
  "code": "ICSS-DIAG-409-CONTEXT_REQUIRED",
  "message": "诊断上下文不足，请补充项目、设备或时间范围",
  "requestId": "7e1b7b2f-98bd-4f7f-8f35-c2d6e71f7f31",
  "data": null
}
```

## 5. 统一分页

### 5.1 请求参数

| 参数 | 类型 | 必填 | 默认值 | 规则 |
| --- | --- | --- | --- | --- |
| pageNo | integer | 否 | 1 | >= 1 |
| pageSize | integer | 否 | 20 | 1-100 |
| sortBy | string | 否 | updatedAt | 仅允许接口声明的排序字段 |
| sortOrder | string | 否 | desc | asc/desc |

### 5.2 响应结构

```json
{
  "items": [],
  "pageNo": 1,
  "pageSize": 20,
  "total": 0,
  "hasNext": false
}
```

## 6. 权限标识规范

| 模块 | 权限标识 | 说明 |
| --- | --- | --- |
| 问答会话 | `session:create`、`session:update`、`session:view` | 会话创建、补充、查看 |
| 诊断案例 | `diagnosis:start`、`diagnosis:view` | 发起诊断、查看结论 |
| 执行日志 | `trace:view_summary`、`trace:view_detail`、`trace:view_raw` | 摘要、详细、原始返回分层 |
| 知识录入 | `knowledge:upload`、`knowledge:view`、`knowledge:retry`、`knowledge:publish` | 上传、查看、重跑、发布入图 |
| 图谱查询 | `graph:view`、`graph:edit`、`graph:publish`、`graph:rollback` | 查看、编辑、发布、回滚 |
| MCP 能力 | `mcp:view`、`mcp:update_status`、`mcp:view_call_log` | 查看、启停、调用记录 |
| 路径治理 | `route:view`、`route:feedback`、`route:publish`、`route:disable` | 查看、反馈、固化、停用 |
| 审计 | `audit:view`、`audit:export` | 查看、导出 |

## 7. 幂等规范

| 接口类型 | 幂等要求 |
| --- | --- |
| 创建会话、发起诊断、上传知识源、提交反馈 | 必须传 `X-Idempotency-Key`，同 key 重复请求返回第一次结果 |
| 查询类接口 | 天然幂等，不要求 `X-Idempotency-Key` |
| MCP 启停、图谱发布/回滚、路径固化/停用 | 必须传 `X-Idempotency-Key`，后端需保证状态变更不重复执行 |

## 8. 限流规范

| 场景 | 限流建议 |
| --- | --- |
| 提交问题 | 单用户 30 次/分钟，单项目 300 次/分钟 |
| 发起诊断 | 单用户 10 次/分钟，单项目 100 次/分钟 |
| 查询执行日志 | 单用户 120 次/分钟 |
| 文件上传 | 单用户 20 次/小时 |
| MCP 启停 | 单管理员 20 次/小时 |
| 审计导出 | 单审计用户 10 次/小时 |

## 9. Mock 规范

| 场景 | Mock 要求 |
| --- | --- |
| 成功诊断 | 返回 concluded case、completed trace、至少 2 条 graphPaths、至少 1 条 mcpCalls |
| 上下文不足 | 返回 `ICSS-DIAG-409-CONTEXT_REQUIRED`，并给出 missingFields |
| MCP 降级 | trace.degraded=true，mcpCalls 中至少 1 条 failed 或 timeout |
| 权限不足 | 返回 `ICSS-AUTH-403-PROJECT_DENIED` 或 `ICSS-AUTH-403-FIELD_DENIED` |
| 路径重建 | submitAnswerFeedback 返回 routeStatus=reviewing |

## 10. 字段脱敏规范

| 字段类型 | R-CS | R-OPS/R-RD | R-ADMIN | R-AUDIT |
| --- | --- | --- | --- | --- |
| MCP requestSummary | 摘要 | 详细 | 详细 | 详细只读 |
| MCP responseSummary | 摘要 | 详细 | 详细 | 详细只读 |
| rawResponseRef | 不返回 | 条件返回 | 返回 | 条件返回 |
| knowledgeSource.objectKey | 不返回 | 条件返回 | 返回 | 条件返回 |
| audit.detailPayload | 不返回 | 条件返回 | 返回 | 返回 |
