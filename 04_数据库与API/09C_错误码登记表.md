# Intelligent Customer Service System 错误码登记表

## 1. 错误码规则

- 格式：`ICSS-{DOMAIN}-{HTTP_STATUS}-{REASON}`
- 成功码：`0`
- 每个业务错误码只能对应一个业务含义，不允许复用。

## 2. 错误码清单

| 错误码 | HTTP | 含义 | 触发条件 | 前端处理建议 |
| --- | --- | --- | --- | --- |
| ICSS-AUTH-401-UNAUTHORIZED | 401 | 未登录或 Token 无效 | 缺少 Authorization 或 Token 过期 | 跳转登录或刷新 Token |
| ICSS-AUTH-403-PROJECT_DENIED | 403 | 项目无权限 | 用户访问未授权 projectId | 提示无项目权限 |
| ICSS-AUTH-403-FIELD_DENIED | 403 | 字段无权限 | 访问原始 MCP 返回等敏感字段 | 隐藏字段并提示权限不足 |
| ICSS-AUTH-403-OPERATION_DENIED | 403 | 操作无权限 | 非管理员启停 MCP、发布图谱等 | 禁用按钮或提示联系管理员 |
| ICSS-COMMON-400-INVALID_PARAMETER | 400 | 参数不合法 | 类型、长度、枚举、必填校验失败 | 标记表单字段 |
| ICSS-COMMON-404-NOT_FOUND | 404 | 资源不存在 | ID 不存在或已删除 | 提示数据不存在并刷新列表 |
| ICSS-COMMON-409-DUPLICATE_REQUEST | 409 | 重复请求 | 幂等 key 重复且请求体不一致 | 提示不要重复提交 |
| ICSS-COMMON-429-RATE_LIMITED | 429 | 请求过于频繁 | 命中限流策略 | 提示稍后重试 |
| ICSS-DIAG-400-QUESTION_EMPTY | 400 | 问题为空 | questionText 去空后为空 | 提示输入问题 |
| ICSS-DIAG-409-CONTEXT_REQUIRED | 409 | 诊断上下文不足 | 缺项目、设备、时间等关键字段 | 展示追问字段 |
| ICSS-DIAG-404-SESSION_NOT_FOUND | 404 | 会话不存在 | sessionId 不存在或无权限 | 返回工作台或刷新 |
| ICSS-DIAG-404-CASE_NOT_FOUND | 404 | 诊断案例不存在 | caseId 不存在或无权限 | 返回列表或刷新 |
| ICSS-DIAG-409-CASE_NOT_READY | 409 | 案例状态不允许操作 | 未到可诊断或可反馈状态 | 根据状态刷新页面 |
| ICSS-TRACE-404-NOT_FOUND | 404 | 执行轨迹不存在 | traceId 不存在或无权限 | 提示轨迹不存在 |
| ICSS-TRACE-409-INCOMPLETE | 409 | 执行轨迹不完整 | trace 状态 partial/failed 且请求详细内容 | 展示降级说明 |
| ICSS-KNOW-400-UNSUPPORTED_SOURCE_TYPE | 400 | 知识源类型不支持 | sourceType 不在白名单 | 提示支持格式 |
| ICSS-KNOW-413-FILE_TOO_LARGE | 413 | 文件过大 | 超过 50MB 或页数/图片数限制 | 提示拆分上传 |
| ICSS-KNOW-409-SOURCE_DUPLICATED | 409 | 知识源重复 | 同项目同 hash 未删除记录已存在 | 提示已上传 |
| ICSS-KNOW-404-SOURCE_NOT_FOUND | 404 | 知识源不存在 | sourceId 不存在或无权限 | 刷新列表 |
| ICSS-KNOW-409-TASK_RUNNING | 409 | 入图任务运行中 | 重跑或发布时仍有任务运行 | 等待任务完成 |
| ICSS-GRAPH-400-INVALID_QUERY | 400 | 图谱查询条件非法 | keyword、entityType、relationType 不合法 | 修正查询条件 |
| ICSS-GRAPH-404-ASSET_NOT_FOUND | 404 | 图谱资产不存在 | graphId 不存在或无权限 | 刷新图谱列表 |
| ICSS-GRAPH-409-CONFLICT_RELATION | 409 | 图谱关系存在冲突 | 发布时仍有低置信度或冲突关系 | 进入复核流程 |
| ICSS-GRAPH-409-REVISION_LOCKED | 409 | 图谱版本不可修改 | 已发布或已回滚版本被编辑 | 新建草稿版本 |
| ICSS-MCP-404-CAPABILITY_NOT_FOUND | 404 | MCP 能力不存在 | capabilityId/code 不存在 | 刷新能力列表 |
| ICSS-MCP-409-CAPABILITY_DISABLED | 409 | MCP 能力已停用 | 路径引用 disabled 能力 | 触发路径重规划 |
| ICSS-MCP-409-CAPABILITY_UNHEALTHY | 409 | MCP 能力异常 | 健康检查失败且禁止自动调用 | 展示异常状态 |
| ICSS-MCP-409-IMPACT_CONFIRM_REQUIRED | 409 | 停用前需要确认影响范围 | 未确认受影响路径和近 7 天调用量 | 弹出影响确认 |
| ICSS-ROUTE-404-NOT_FOUND | 404 | 诊断路径不存在 | routeId 不存在或无权限 | 刷新路径列表 |
| ICSS-ROUTE-409-REVIEW_REQUIRED | 409 | 路径需要复核 | 无效反馈、连续失败、MCP 停用 | 引导进入复核 |
| ICSS-ROUTE-409-SCOPE_CONFLICT | 409 | 路径作用域冲突 | 同项目同问题类型存在冲突 active 路径 | 提示停用旧路径 |
| ICSS-ROUTE-409-FEEDBACK_DUPLICATED | 409 | 反馈重复 | 同用户对同 trace 重复提交 | 展示已提交反馈 |
| ICSS-AUDIT-403-EXPORT_DENIED | 403 | 审计导出无权限 | 非审计或管理员导出 | 隐藏导出入口 |
| ICSS-AUDIT-404-NOT_FOUND | 404 | 审计记录不存在 | auditId 不存在或无权限 | 刷新审计列表 |
| ICSS-SYS-500-INTERNAL_ERROR | 500 | 系统内部错误 | 未预期异常 | 提示稍后重试并上报 requestId |
| ICSS-SYS-503-DOWNSTREAM_UNAVAILABLE | 503 | 下游不可用 | AI Service、MCP Server、Neo4j 等不可用 | 展示降级或稍后重试 |
