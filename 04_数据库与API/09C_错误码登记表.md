# Intelligent Customer Service System 错误码登记表

## 1. 错误码规则

- 格式：`ICSS-{DOMAIN}-{HTTP_STATUS}-{REASON}`
- 成功码：`0`
- 每个业务错误码只能对应一个业务含义，不允许复用。
