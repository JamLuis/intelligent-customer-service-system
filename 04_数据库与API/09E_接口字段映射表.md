| sessionId | support_session.session_id | 会话 ID |

| sourceId | knowledge_source.source_id | 知识源 ID |
| sourceType | knowledge_source.source_type | 知识源类型 |
| parserStatus | knowledge_source.parser_status | 解析状态 |
| graphId | graph_asset.graph_id | 图谱资产 ID |
| graphVersion | graph_revision.revision_no | 图谱版本 |
