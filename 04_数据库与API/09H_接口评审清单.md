# 接口评审清单

## 1. 出口检查

- [ ] 每个接口有编号、URL、Method、权限标识。
- [ ] 每个写接口有幂等说明。
- [ ] 每个列表接口使用统一分页结构。
- [ ] 每个错误场景引用 09C 中的唯一错误码。
- [ ] 每个接口有 Mock 规则。
- [ ] 每个接口有 DB 表映射。
- [ ] 客服、运维、研发、管理员、审计字段权限已区分。
- [ ] 真实 wnx 接入只替换 Adapter，不改变前端 API。
